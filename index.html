คำถามที่พบบ่อย (2025)

รับ Bitcoin ต้องทำอย่างไร? +
แนะนำให้ใช้ Lightning Wallet ซึ่งรวดเร็วและค่าธรรมเนียมต่ำมาก
  • Wallet of Satoshi: (Custodial) ใช้งานง่ายที่สุด เหมาะสำหรับมือใหม่ โหลดแล้วรับเงินได้เลย
  • Phoenix / Breez: (Non-custodial) สำหรับผู้ที่ต้องการความเป็นส่วนตัวและควบคุม Private Key เอง
เพียงดาวน์โหลดแอป สร้าง QR Code ก็พร้อมรับชำระเงินจากลูกค้าได้ทันที
จะถอน Bitcoin เป็นเงินบาท หรือส่งเข้า Exchange ยังไง? +
ในปัจจุบัน (2025) การโอนผ่าน Lightning Network คือวิธีที่ดีที่สุด แนะนำช่องทางดังนี้:
  • Exchange ต่างประเทศ: ใช้ Binance Global, OKX หรือ Kraken ที่รองรับการฝากถอนผ่าน Lightning โดยตรง
  • Bridge/Swap Services: ใช้บริการอย่าง FixedFloat.io หรือ Boltz.exchange เพื่อแปลง Bitcoin (Lightning) เป็น Stablecoin หรือ Coin อื่นๆ เข้า Exchange ไทย
*หมายเหตุ: Exchange ไทยส่วนใหญ่ยังรองรับเฉพาะ On-chain transaction ซึ่งช้าและมีค่าธรรมเนียมสูงกว่า
